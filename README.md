# 피카 데이 ⚡

흰 제복 모자와 금색 문장을 쓴 캡틴 피카츄가 오늘의 업무와 회의를 챙겨주는 Windows 데스크톱 앱입니다. 사용자 사진을 참고한 SVG 일러스트로, 팔짱을 낀 모습과 기존 10가지 표정을 함께 제공합니다.

- Slack·Gmail·Jira에서 할 일 또는 할 일 후보 수집, P1/P2 정렬, 원문 보기
- Google Calendar 회의 수집, 시작 10분 전 리마인드, HTTPS 참가 링크
- 5분 간격 수집, 새 항목 중복 방지, 서비스별 새 할 일 수 및 P1/P2 요약
- 실제 완료 수에 따른 응원 (`벌써 절반 했어요! (4/8)`)
- 비장 / 들뜬 / 자신 있는 / 기쁜 / 졸림 / 시무룩 / 놀람 / 장난 / 화남 / 집중: 총 10가지 표정. 사진을 참고해 앱 일러스트 스타일로 구현했습니다.
- 표정 미리보기, 25분 집중 모드, 5분 쉬기 모드. 20분 조용하면 졸림, 미완료 업무 10개 이상이면 시무룩, 새 할 일 3개 이상이면 놀람, 수집 오류 시 화남 표정으로 전환합니다.
- 창을 닫으면 트레이 유지. 트레이의 **완전히 종료**를 선택하면 수집과 알림이 중단됩니다.

## 내 이미지를 메인 화면에 사용

메인 캐릭터 위의 **내 이미지 선택**으로 PNG, JPG 또는 WebP 원본 파일(최대 3MB)을 선택하세요. 선택한 파일은 변형 없이 이 기기에 저장되어 다음 실행에도 유지됩니다. 서버로 전송되지 않습니다. **내 그림 보기**와 **표정 모드**를 전환할 수 있으며, 표정 미리보기에서는 동적인 SVG 캐릭터를 사용합니다. 원본 사진 자체의 얼굴을 자동으로 수정하지는 않습니다. **이미지 지우기**를 누르면 기본 캡틴 피카츄로 돌아갑니다.

## Windows에서 사용

`dist/PikaDay-Windows-x64.zip`을 **폴더 전체로 압축 해제**한 뒤 `PikaDay.exe`를 실행합니다. 실행 파일만 이동하면 필요한 라이브러리를 찾을 수 없습니다. 설치형 프로그램이 아닌 포터블 배포이며, Windows 실기기 실행은 아직 검증하지 않았습니다.

앱의 **연결 안내**에서 OAuth 토큰을 입력하고 **안전하게 저장**을 선택하면 실제 수집을 시작합니다. 앱에 저장하는 토큰은 Electron safeStorage를 통해 Windows의 DPAPI로 암호화되며 토큰을 화면에 다시 표시하거나 localStorage에 넣지 않습니다. 안전한 OS 저장소가 없는 환경에서는 평문 저장하지 않고 저장을 거부합니다. 앱 시작 시 환경 변수로 주어진 연결도 사용할 수 있습니다.

현재 버전에는 OAuth 로그인 버튼이나 토큰 자동 갱신이 없습니다. 조직에서 승인한 앱의 토큰을 사용해야 하며, 만료되면 갱신한 토큰을 입력해야 합니다. **이 대화에 연결한 서비스 계정 권한은 배포 앱에 자동으로 전달되지 않습니다.** 토큰을 채팅으로 보내지 마세요.

### 필요한 연결 권한

| 서비스 | 설정 | 읽기 권한 / 목적 |
| --- | --- | --- |
| Slack | `SLACK_USER_TOKEN` | 사용자 OAuth 토큰의 `search:read`. 최근 7일의 나에게 온 메시지 중 요청 키워드가 있는 최대 50개 검색 결과에서 할 일 후보 수집. 봇 토큰으로 검색할 수 없습니다. |
| Gmail | `GMAIL_ACCESS_TOKEN` | `https://www.googleapis.com/auth/gmail.readonly`. 최근 7일의 받은편지함에 있는 읽지 않은 메일 최대 25개에서 요청 키워드가 있는 후보 수집. |
| Google Calendar | 같은 `GMAIL_ACCESS_TOKEN` | `https://www.googleapis.com/auth/calendar.events.readonly`도 함께 승인. 기본 캘린더의 향후 7일 일정 최대 50개 수집. 시작 시간이 있는 일정만 포함하며, 취소되거나 참가 거절한 일정은 제외. |
| Jira (선택) | `JIRA_ACCESS_TOKEN`, `JIRA_CLOUD_ID` | Atlassian OAuth 토큰의 `read:jira-work`. 내게 할당된 미해결 이슈 최대 50개 수집. Cloud ID는 토큰이 아닌 사이트 식별자입니다. |

연결 확인은 실제 API 응답을 기준으로 하며 토큰이 있다고 연결 완료로 표시하지 않습니다. 일부 서비스에 오류가 발생해도 다른 서비스의 성공한 결과를 유지합니다. 클라우드 프록시에 주입된 비밀 값은 해당 서비스의 허용된 HTTPS 경로에서만 사용합니다.

### 수집과 분류의 범위

현재는 AI 의미 분석이 아닌 **요청·검토·마감 등 키워드 기반** 수집입니다. Slack·Gmail에는 `확인할 후보` 표시가 붙으므로 원문을 확인하세요. 긴급/마감/ASAP 표현은 P1, 그 외는 P2입니다. Jira는 High/Highest/Critical/Blocker 우선순위를 P1로 분류합니다. 페이지네이션 전체 수집, 과거 모든 업무 수집, 자동 작업 완료 판정은 제공하지 않습니다.

완료한 수집 항목은 다시 수집해도 완료 상태를 유지하며, 삭제한 항목은 다시 추가하지 않습니다. 새 항목이 없거나 서비스 미연결일 때는 가짜 할 일을 만들지 않습니다. **예시 체험**은 명확히 표시되는 샘플 데이터로 실제 수집 결과가 아닙니다.

알림은 앱이 실행 중일 때만 제공됩니다. 알림 클릭으로 회의 참가 링크를 열 수 있습니다. 운영체제에서 알림을 허용해야 하며, PC가 잠들어 있으면 정각 알림은 보장되지 않습니다. 알림 시점을 놓쳤더라도 회의 시작 전 앱이 다시 실행되면 남은 시간으로 알립니다. 앱에는 회의 참가 버튼을 항상 제공합니다. 알림 및 새 할 일 정보는 외부로 전송하지 않습니다.

데이터와 일정은 해당 컴퓨터에만 저장됩니다. 로그아웃/연결 삭제는 OAuth 토큰을 지우며 이미 수집한 할 일이나 일정을 지우지는 않습니다. 회의 일정 변경과 취소는 다음 성공한 캘린더 수집에 반영됩니다.

## 개발 환경

Node.js 22 이상과 npm을 사용합니다. 기존 체크아웃을 사용하세요.

```sh
npm ci
npm start
```

데스크톱을 표시할 수 없는 환경에서는 브라우저 버전으로 기능을 검증할 수 있습니다.

```sh
npm run web
```

기본 포트는 웹 버전 3000, 데스크톱 내부 서버 3417입니다. 웹 버전의 회의 알림은 페이지를 열어둔 동안만 동작하며 보안 토큰 입력 UI는 데스크톱에만 제공합니다. 클라우드 프록시 환경에서 Electron 다운로드에는 `ELECTRON_GET_USE_PROXY=1`과 `GLOBAL_AGENT_HTTP_PROXY`를 기존 HTTPS 프록시로 설정해야 할 수 있습니다. TLS/체크섬 검증은 유지하세요.

## 테스트 및 Windows 빌드

```sh
npm test
npm run package:windows
```

유닛 테스트는 수집 API 응답 변환, 인증 오류 분리, 리마인드 시각 및 중복 방지, 링크 검증, 보안 저장소를 확인합니다. API 테스트는 목 데이터를 사용하며 실제 계정 연동 성공을 의미하지 않습니다. Linux Electron에서 네이티브 창과 IPC, 창 닫기 후 트레이 유지 및 숨긴 창에 리마인드 전달을 검증했습니다. Windows 빌드는 크로스 빌드하며 코드 서명과 Windows 실기기 알림 확인은 포함하지 않습니다.
