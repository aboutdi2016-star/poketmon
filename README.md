# 피카 데이 ⚡

흰 제복 모자와 금색 문장을 쓴 캡틴 피카츄가 오늘의 업무와 회의를 챙겨주는 Windows 데스크톱 앱입니다. 사용자가 첨부한 원본 이미지를 사용하며 배경만 투명하게 처리했습니다. 그림을 다시 그리지 않았습니다.

- Slack·Gmail·Jira·Obsidian에서 할 일 또는 할 일 후보 수집, P1/P2 정렬, 원문 보기
- Google Calendar 회의 수집, 시작 10분 전 리마인드, HTTPS 참가 링크
- 5분 간격 수집, 새 항목 중복 방지, 서비스별 새 할 일 수 및 P1/P2 요약
- 실제 완료 수에 따른 응원 (`벌써 절반 했어요! (4/8)`)
- 비장 / 들뜬 / 자신 있는 / 기쁜 / 졸림 / 시무룩 / 놀람 / 장난 / 화남 / 집중: 총 10가지 상황. 졸림·시무룩·놀람·화남은 첨부한 원본 이미지로 전환하고 나머지 상황은 원본 캡틴 이미지와 해당 응원 문구를 사용합니다.
- 표정 미리보기, 25분 집중 모드, 5분 쉬기 모드. 20분 조용하면 졸림, 미완료 업무 10개 이상이면 시무룩, 새 할 일 3개 이상이면 놀람, 수집 오류 시 화남 표정으로 전환합니다.
- 기본 실행 화면은 바탕화면의 작은 피카츄입니다. 전체 화면은 상세 관리용으로 숨겨져 있으며, 창을 닫아도 수집과 알림은 계속됩니다. 트레이의 **완전히 종료**를 선택하면 중단됩니다.

## 바탕화면 피카츄 사용법

앱을 실행하면 큰 화면 대신 배경과 테두리가 없는 작은 피카츄가 오른쪽 아래에 나타납니다. 시작 안내와 알림 말풍선은 잠시 후 사라집니다.

- 피카츄 클릭: 작은 할 일 패널. 할 일 추가·완료, 진행률, 회의 목록과 참가 버튼을 제공합니다.
- 피카츄 드래그: 위치 이동. 다음 실행에도 위치가 유지되며, 모니터가 없어지면 현재 화면 안으로 돌아옵니다.
- 알림 말풍선: 새 업무 요약, 회의 시작 10분 전 알림과 참가 버튼, 완료 응원. 패널을 사용하는 동안 일반 알림은 대기하고 완료 응원은 패널에도 표시됩니다.
- 패널의 **전체 화면**: 전체 목록 관리. **설정**: 서비스 연결 안내와 안전한 토큰 등록.
- 피카츄 오른쪽 클릭 또는 Windows 시계 옆 트레이 메뉴: 표시·숨기기, 다른 창 위에 표시, 위치 초기화, 집중·쉬기, 완전히 종료.
- Windows에서는 피카츄 주변의 투명한 부분을 클릭하면 뒤쪽 프로그램으로 전달되도록 처리합니다. 피카츄 자체는 클릭과 드래그를 받습니다.

Windows 자동 시작 등록은 하지 않습니다. 앱이 실행된 동안만 수집과 알림이 동작합니다. 웹 모드에서는 전체 화면을 사용하며 바탕화면 캐릭터 창은 Electron 데스크톱에서만 제공됩니다.

## 옵시디언 연결

피카츄를 클릭한 뒤 **설정 → 옵시디언 연결 → 보관함 폴더 선택**을 누르세요. `.obsidian` 폴더가 들어 있는 보관함 루트를 선택하면 됩니다. OAuth 토큰이나 옵시디언 플러그인은 필요하지 않습니다.

Markdown 노트의 `- [ ]` 미완료 체크리스트를 가져옵니다. `#p1`, `#urgent`, `🔺`, `⏫`, 긴급 표현은 P1, 나머지는 P2입니다. 완료된 체크리스트는 처음 연결할 때 가져오지 않습니다. 코드 블록 안의 예시 체크리스트는 제외합니다. 숨김 폴더와 심볼릭 링크는 읽지 않습니다.

노트의 체크박스를 완료하거나 다시 열면 다음 수집에 반영됩니다. 앱에서 체크한 완료 상태는 앱에만 저장되며 Markdown 원본은 수정하지 않습니다. 삭제된 체크리스트는 다음 수집에 목록에서 빠집니다. **노트 열기**로 옵시디언의 원본 노트를 열 수 있습니다. 같은 이름의 보관함이 여러 개 있으면 옵시디언에서 보관함 이름을 구분해 주세요.

5분마다 기존 서비스와 함께 수집하며 **지금 수집**으로 바로 갱신할 수 있습니다. 연결 해제는 가져온 옵시디언 할 일과 폴더 연결을 앱에서 지웁니다. 노트 내용은 외부로 전송되지 않습니다. 한 보관함에서 Markdown 최대 5,000개, 체크리스트 최대 5,000개를 검사하며 노트 하나가 2MB를 넘으면 오류로 표시하고 기존 목록을 유지합니다. 웹 모드에서는 로컬 보관함 선택 기능을 제공하지 않습니다.

## 추가 편의 기능

- **Google 자동 갱신:** 설정의 접힌 `Google 토큰 자동 갱신 설정`에 본인 Google OAuth Client ID, Client secret(해당하는 경우), Refresh token을 한 번 등록하세요. 새 액세스 토큰은 Gmail과 Calendar에 함께 사용하며 만료 전에 갱신합니다. 인증 정보는 기존 OS 보안 저장소에 암호화됩니다. 기본 OAuth Playground에서 얻은 액세스 토큰만으로는 자동 갱신할 수 없습니다. Google Cloud에서 Gmail·Calendar API와 OAuth 클라이언트를 설정하고, Playground의 `Use your own OAuth credentials`에 동일한 클라이언트를 입력해 갱신 토큰을 발급해야 합니다. Playground를 쓰는 웹 클라이언트의 승인된 리디렉션 URI는 `https://developers.google.com/oauthplayground`입니다. 테스트 모드의 갱신 토큰은 Google 정책에 따라 만료될 수 있습니다.
- **10분 뒤 다시 알림:** 말풍선의 `10분 뒤` 버튼. 미룬 알림은 앱 재실행 후에도 유지되며 앱이 실행된 동안 재알림됩니다. 회의 시작 후 10분이 넘은 알림은 다시 표시하지 않습니다.
- **조용한 시간:** 설정에서 시작·종료 시간을 저장하세요. 자정을 넘는 시간대를 지원하며, 같은 시간으로 설정하면 하루 전체입니다. 말풍선과 시스템 알림을 끄고 수집과 회의 목록은 유지합니다. 시간을 다시 열어도 이미 지나간 회의 알림을 새로 만들지는 않습니다.
- **오늘 필터:** 전체 화면의 `오늘` 탭 또는 작은 패널의 날짜 선택. 옵시디언 `📅 YYYY-MM-DD`, `due:: YYYY-MM-DD`, `⏳ YYYY-MM-DD`, `#today`, `#오늘`을 읽습니다. 오늘까지 마감인 일과 오늘 태그를 표시하고, 날짜 없는 옵시디언 할 일은 전체 목록에서 봅니다. 날짜 없는 직접 등록·서비스 할 일은 오늘 목록에도 표시됩니다.
- **하루 요약 저장:** 작은 패널이나 설정에서 누르면 보관함의 `Pika Day/YYYY-MM-DD.md`에 집중 시간, 앱에 기록된 오늘 완료 목록, 내일 검토할 남은 일을 저장합니다. 미래 마감일의 업무는 내일 목록에서 제외합니다. 보고서의 관리 영역만 갱신하고 바깥쪽 사용자 메모는 보존합니다. 보고서 폴더는 체크리스트 수집에서 제외하여 중복 수집을 방지합니다. 예전 버전에서 완료 날짜 없이 저장된 항목은 오늘 완료로 추정하지 않습니다.
- **집중 기록:** 작은 패널·트레이·전체 화면에서 25분 집중을 시작하거나 중간에 마칠 수 있습니다. 실제 경과 시간을 기록하고 완주하면 응원합니다. 앱 종료나 PC 절전 시 집중을 마감하여 닫혀 있는 시간을 집중으로 기록하지 않습니다. 시간·완료 기록은 이 컴퓨터의 현지 날짜를 기준으로 합니다.

## 다양한 피카츄 멘트

업무 시작, P1, 새 업무, 놀람, 완료·절반·한 걸음 응원, 업무 과부하, 연결 오류, 졸림, 쉬기, 집중, 회의 등 15가지 상황에 총 60개 멘트를 제공합니다. 같은 상황의 직전 멘트를 연속 선택하지 않으며, 단순 화면 갱신에서는 멘트를 유지합니다. 완료 수와 회의까지 남은 시간은 실제 데이터를 사용합니다. 멘트는 말풍선 텍스트이며 음성 재생 기능은 아닙니다.

## 내 이미지를 메인 화면에 사용

메인 캐릭터 위의 **내 이미지 선택**으로 PNG, JPG 또는 WebP 원본 파일(최대 3MB)을 선택하세요. 선택한 파일은 변형 없이 이 기기에 저장되어 다음 실행에도 유지됩니다. 서버로 전송되지 않습니다. **내 그림 보기**와 **표정 모드**를 전환할 수 있으며, 표정 미리보기에서도 첨부한 원본 이미지를 사용합니다. 원본 사진 자체의 얼굴을 자동으로 수정하지는 않습니다. **이미지 지우기**를 누르면 기본 캡틴 피카츄로 돌아갑니다.

## Windows에서 사용

`dist/PikaDay-Windows-x64.zip`을 **폴더 전체로 압축 해제**한 뒤 `PikaDay.exe`를 실행합니다. 실행 파일만 이동하면 필요한 라이브러리를 찾을 수 없습니다. 설치형 프로그램이 아닌 포터블 배포이며, Windows 실기기 실행은 아직 검증하지 않았습니다.

앱의 **연결 안내**에서 OAuth 토큰을 입력하고 **안전하게 저장**을 선택하면 실제 수집을 시작합니다. 앱에 저장하는 토큰은 Electron safeStorage를 통해 Windows의 DPAPI로 암호화되며 토큰을 화면에 다시 표시하거나 localStorage에 넣지 않습니다. 안전한 OS 저장소가 없는 환경에서는 평문 저장하지 않고 저장을 거부합니다. 앱 시작 시 환경 변수로 주어진 연결도 사용할 수 있습니다.

현재 버전에는 OAuth 로그인 버튼은 없습니다. Google은 본인 OAuth 클라이언트 ID와 갱신 토큰을 등록하면 자동 갱신을 지원하며, Slack 토큰 자동 갱신은 아직 제공하지 않습니다. 조직에서 승인한 앱의 토큰을 사용해야 하며, 만료되면 갱신한 토큰을 입력해야 합니다. **이 대화에 연결한 서비스 계정 권한은 배포 앱에 자동으로 전달되지 않습니다.** 토큰을 채팅으로 보내지 마세요.

### 필요한 연결 권한

| 서비스 | 설정 | 읽기 권한 / 목적 |
| --- | --- | --- |
| Slack | `SLACK_USER_TOKEN` | 사용자 OAuth 토큰의 `search:read`. 최근 7일의 나에게 온 메시지 중 요청 키워드가 있는 최대 50개 검색 결과에서 할 일 후보 수집. 봇 토큰으로 검색할 수 없습니다. |
| Gmail | `GMAIL_ACCESS_TOKEN` | `https://www.googleapis.com/auth/gmail.readonly`. 최근 7일의 받은편지함에 있는 읽지 않은 메일 최대 25개에서 요청 키워드가 있는 후보 수집. |
| Google Calendar | 같은 `GMAIL_ACCESS_TOKEN` | `https://www.googleapis.com/auth/calendar.events.readonly`도 함께 승인. 기본 캘린더의 향후 7일 일정 최대 50개 수집. 시작 시간이 있는 일정만 포함하며, 취소되거나 참가 거절한 일정은 제외. |
| Jira (선택) | `JIRA_ACCESS_TOKEN`, `JIRA_CLOUD_ID` | Atlassian OAuth 토큰의 `read:jira-work`. 내게 할당된 미해결 이슈 최대 50개 수집. Cloud ID는 토큰이 아닌 사이트 식별자입니다. |

연결 확인은 실제 API 응답을 기준으로 하며 토큰이 있다고 연결 완료로 표시하지 않습니다. 일부 서비스에 오류가 발생해도 다른 서비스의 성공한 결과를 유지합니다. 클라우드 프록시에 주입된 비밀 값은 해당 서비스의 허용된 HTTPS 경로에서만 사용합니다.

### 수집과 분류의 범위

현재는 AI 의미 분석이 아닌 **요청·검토·마감 등 키워드 기반** 수집입니다. Slack·Gmail에는 `확인할 후보` 표시가 붙으므로 원문을 확인하세요. 긴급/마감/ASAP 표현은 P1, 그 외는 P2입니다. Jira는 High/Highest/Critical/Blocker 우선순위를 P1로 분류합니다. 페이지네이션 전체 수집, 과거 모든 업무 수집, 자동 작업 완료 판정은 제공하지 않습니다.

완료한 수집 항목은 다시 수집해도 완료 상태를 유지하며, 삭제한 항목은 다시 추가하지 않습니다. 새 항목이 없거나 서비스 미연결일 때는 가짜 할 일을 만들지 않습니다. **예시 체험**은 명확히 표시되는 샘플 데이터로 실제 수집 결과가 아닙니다.

알림은 앱이 실행 중일 때만 제공됩니다. 알림 클릭으로 회의 참가 링크를 열 수 있습니다. 운영체제에서 알림을 허용해야 하며, PC가 잠들어 있으면 정각 알림은 보장되지 않습니다. 알림 시점을 놓쳤더라도 회의 시작 전 앱이 다시 실행되면 남은 시간으로 알립니다. 앱에는 회의 참가 버튼을 항상 제공합니다. 알림 및 새 할 일 정보는 외부로 전송하지 않습니다.

데이터와 일정은 해당 컴퓨터에만 저장됩니다. 로그아웃/연결 삭제는 OAuth 토큰을 지우며 이미 수집한 할 일이나 일정을 지우지는 않습니다. 회의 일정 변경과 취소는 다음 성공한 캘린더 수집에 반영됩니다.

## 개발 환경

Node.js 22 이상과 npm을 사용합니다. 기존 체크아웃을 사용하세요.

```sh
npm ci
npm start
```

데스크톱을 표시할 수 없는 환경에서는 브라우저 버전으로 기능을 검증할 수 있습니다.

```sh
npm run web
```

기본 포트는 웹 버전 3000, 데스크톱 내부 서버 3417입니다. 웹 버전의 회의 알림은 페이지를 열어둔 동안만 동작하며 보안 토큰 입력 UI는 데스크톱에만 제공합니다. 클라우드 프록시 환경에서 Electron 다운로드에는 `ELECTRON_GET_USE_PROXY=1`과 `GLOBAL_AGENT_HTTP_PROXY`를 기존 HTTPS 프록시로 설정해야 할 수 있습니다. TLS/체크섬 검증은 유지하세요.

## 테스트 및 Windows 빌드

```sh
npm test
npm run package:windows
```

유닛 테스트는 수집 API 응답 변환, 인증 오류 분리, 리마인드 시각 및 중복 방지, 링크 검증, 보안 저장소를 확인합니다. API 테스트는 목 데이터를 사용하며 실제 계정 연동 성공을 의미하지 않습니다. Linux Electron에서 숨겨진 전체 화면, 작은 캐릭터 창, 패널의 할 일 추가·완료, 완료 응원, 회의 말풍선과 참가 링크 전달, 알림 중복 방지, 위치 저장 및 재실행을 검증했습니다. Windows의 실제 창 투명 표시와 뒤쪽 프로그램으로 클릭 전달은 Windows PC에서 최종 확인이 필요합니다. Windows 빌드는 크로스 빌드하며 코드 서명과 Windows 실기기 알림 확인은 포함하지 않습니다.

배경 제거 PNG 5장은 릴리스의 `PikaDay-Transparent-Images.zip`에서 받을 수 있습니다. 원본에서 프레임 밖으로 잘린 부분은 새로 그리지 않고 유지했습니다.
