나의 서비스 연결

대화에 연결된 계정 권한은 앱에 자동으로 전달되지 않아요. 서비스에서 발급한 OAuth 토큰을 앱의 안전한 저장소에 등록하거나, 앱 실행 환경에 설정해야 실제 수집이 가능합니다. 로그인 버튼으로 계정을 연결하는 흐름은 아직 제공하지 않습니다.

  • Slack: 검색 권한이 있는 사용자 토큰
  • Gmail: 메일 읽기 권한
  • Google Calendar: 일정 읽기 권한
  • Jira: 내 이슈 읽기 권한 (선택)

자세한 설정은 프로젝트 README의 연결 안내를 참고하세요. 인증 정보는 채팅에 보내지 마세요.

자동 수집은 5분마다 최근 항목을 확인합니다. Slack·Gmail 요약은 요청 키워드를 기준으로 찾은 후보이며 확인이 필요해요.

Google 토큰 자동 갱신 설정

본인의 Google OAuth 클라이언트로 발급한 갱신 토큰을 등록하면 앱이 액세스 토큰을 자동 갱신합니다. OAuth Playground의 톱니바퀴에서 Use your own OAuth credentials를 켜고, 같은 클라이언트 ID/비밀번호로 Gmail·Calendar 읽기 권한을 승인해 발급하세요. 기본 Playground 액세스 토큰만으로는 자동 갱신할 수 없습니다.

토큰은 이 컴퓨터의 OS 보안 저장소로 암호화됩니다. 만료 시 새 토큰을 등록해야 합니다. Google은 Gmail·Calendar 권한을 함께 승인한 토큰을 사용하세요.
